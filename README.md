# Proyecto-final-multivariado
Proyecto final de la clase de análisis multivariado. Análisis exploratorio de la base de datos "SocialMedia, Dopamine, and Productivity Dataset" utilizando técnicas de análisis multivariado.

**Pregunta de investigación:** ¿Una mayor frecuencia de revisión de las redes sociales se relaciona directamente con una reducción y fragmentación de la capacidad de concentración?

La base de datos utilizada se puede encontrar en: https://www.kaggle.com/datasets/manaswinsripatnala/social-media-dopamine-and-productivity-dataset
